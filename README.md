# log-analyzer

A small, dependency-free command-line tool that parses web server access logs
(Apache/Nginx *combined* format), aggregates them, and prints an actionable report.

Built as my submission for the **Enterprise Automation Services** trainee / junior
DevOps engineer technical challenge.

Full documentation (what it does, how to run it, how it works, and what I would
improve with more time) is completed in this README as the project develops.
